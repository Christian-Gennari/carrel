# UI

Calm, typographic, keyboard-first. A mouse/trackpad works but is never needed.

## Editor (the default screen)

- Full screen text, centered column (~70 characters), generous line height.
- Markdown shown inline: `**bold**` renders bold with dimmed markers;
  headings larger; `> quotes` indented; `nostos:cite/` links show as a small
  superscript marker.
- Bottom line (F1 hides/shows): words in file · today's words / goal · battery
  · optional clock. Nothing else.
- Typewriter scrolling: the current line stays near the vertical center.
- Focus mode (Settings, off by default; toggle with F2): paragraphs other than
  the one with the cursor are drawn at 35 % opacity. No animation.
- Goal progress (Settings: "Numbers" (default) or "Hairline"): Hairline hides
  the word counts from the bottom line and draws a 2 px line along the bottom
  edge that fills from left to right toward the daily goal, in the accent
  color. It is full (not over-full) when the goal is reached.
- Optional typewriter mode (Settings): Backspace and Delete do nothing.

## Keys

| Key | Action |
|---|---|
| Ctrl+O | Files screen |
| Ctrl+N | New file (named from first line; rename later) |
| Ctrl+H | History of the current file |
| Ctrl+] | Quotes palette (Nostos library) |
| Ctrl+Shift+S | Sync now |
| Ctrl+E | Export screen |
| Ctrl+, | Settings |
| F1 | Show/hide bottom line |
| Ctrl+= / Ctrl+- | Font size |
| Esc | Back to the editor from any screen |

## Screens

- **Files**: folders and files, search by name, new folder, rename, move,
  delete (confirmation). Conflict copies marked.
- **History**: list of versions by time with word count delta; preview; Restore
  (confirmation).
- **Quotes**: type to search; filters by book/author/topic; Enter inserts
  `> quote` + citation link; Shift+Enter inserts the citation only.
- **Export**: choose what (current file / a folder / everything), format
  (Markdown, Plain text, Word .docx, OpenDocument .odt, PDF, HTML, EPUB) and
  destination (USB drive). When a USB drive is plugged in, the screen lists it;
  without one it says "Insert a USB drive". "Everything" writes a dated folder
  (`Carrel export 2026-11-12/`) that keeps the folder structure. Citations
  become footnotes in .docx/.odt/PDF/EPUB. A finished export shows the path
  and "Safe to remove". **Import** from the same screen copies `.md`/`.txt`
  files from the USB drive into `/data/writing/Imported/`.
- **Battery**: the bottom line shows the percentage and a charging mark. When
  F1 hides the bottom line, the battery still shows for 5 s at 10 % and 5 %.
  At 3 % the device saves, commits history and suspends. Values come from
  UPower over D-Bus.
- **Wi-Fi** (Settings → Wi-Fi): scan list with signal strength and lock icon,
  type the password, Connect, Forget. Known networks are saved
  (NetworkManager). Hidden networks: "Other network…". The radio is on only
  while this screen is open, then blocked again. Captive portals (hotel login
  pages) are not supported, because they need a browser; the screen says
  "This network needs a login page. Use a phone hotspot."
- **Sync**: one progress line, last sync time, result. Pair/unpair here.
- **Settings**: Theme (Paper / Night), Font (Serif / Sans / Mono), Size, Daily
  goal, Typewriter mode, Spellcheck (off by default), Clock, Wi-Fi networks,
  Sync backends (Nostos, Self-hosted, Google Drive), Sync at shutdown, Keyboard layout, Language, Time zone, Update
  (shows "Update ready" + Apply), About.
- **First run**: Language → Keyboard → Time zone → "Connect sync?" (Not now /
  Nostos / Self-hosted) → Editor.

## Visual

- Themes: Paper (warm off-white, near-black ink) and Night (dark grey, soft
  white). No pure black/white.
- Fonts (bundled, open licenses): a book serif (e.g. Source Serif 4), a sans
  (e.g. Inter), a mono (e.g. JetBrains Mono).
- Accent color: one low-saturation color per theme, used ONLY for the text
  cursor, the hairline progress line and the selected row. Paper: terracotta
  `#C85A32`; Night: amber `#E5A93B`. Citation markers use the dim text
  color, not the accent.
- Palette: Paper background `#F6F4EE`, ink `#262523`; Night background
  `#1E1C1A`, text `#DCDAD5`. Dim text = ink at 55 %.
- Body text: 19 px default (range 16–24 via Ctrl+= / Ctrl+-), line height 1.6,
  column 60–75 characters measured with average character width.
- No animations except a ≤150 ms fade between screens. No caret animation, no
  keystroke sounds.
