# UI

Calm, typographic, keyboard-first. A mouse/trackpad works but is never needed.

## Editor (the default screen)

- Full screen text, centered column (~70 characters), generous line height.
- Markdown shown inline: `**bold**` renders bold with dimmed markers;
  headings larger; `> quotes` indented; `nostos:cite/` links show as a small
  superscript marker.
- Bottom line (F1 hides/shows): words in file · today's words / goal · battery
  · optional clock, then a dim Ctrl+K key cap. Nothing else.
- An empty document shows one quiet line in the dim colour where the text
  will begin: “Start writing. Ctrl+K for everything else.” It leaves with the
  first typed character and does not return while that document stays open.
  No other tips, no pop-ups.
- Typewriter scrolling: the current line stays near the vertical center once
  the caret is past the middle of the page. The first line always keeps a
  comfortable top margin (96 px at the default size), so the start of a file
  is never clipped.
- Focus mode (Settings, off by default; toggle with F2): paragraphs other than
  the one with the cursor are drawn at 35 % opacity. No animation.
- Goal progress (Settings: "Numbers" (default) or "Hairline"): Hairline hides
  the word counts from the bottom line and draws a 2 px line along the bottom
  edge that fills from left to right toward the daily goal, in the accent
  color. It is full (not over-full) when the goal is reached.
- Optional typewriter mode (Settings): Backspace and Delete do nothing.

## Keys

| Key | Action |
|---|---|
| Ctrl+O | Files screen |
| Ctrl+N | New file (named from first line; rename later) |
| Ctrl+H | History of the current file |
| Ctrl+' | Quotes palette at the caret (Nostos library) |
| Ctrl+K | Command palette (every screen but First run) |
| Ctrl+/ | Key sheet |
| Ctrl+Shift+S | Sync now |
| Ctrl+E | Export screen |
| Ctrl+, | Settings |
| F1 | Show/hide bottom line |
| Ctrl+= / Ctrl+- | Font size |
| Esc | Back to the editor from any screen |

## Command palette

- Ctrl+K opens it over the editor and every screen but First run. It is the
  Quotes palette's sheet, centred near the top of the editor column.
- Type to filter, case-insensitive and fuzzy, word by word: “exp” finds
  Export, “dark” finds Theme: Dark. Each row shows the action on the left and
  its key as key caps on the right. Up/Down move, Enter runs, Esc closes.
- An empty query lists the most useful actions first: New file, Open file…,
  Insert quote, Sync now, Export…, History, Turn focus mode on/off, Theme…,
  Settings, Keyboard shortcuts. After those come every other binding and the
  direct values: each theme by name, the three fonts, Bottom line, Use
  hairline goal / Use word count goal, Turn typewriter mode on/off, Wi-Fi…,
  Pair…, and Update only while an update is ready. A toggle's label names the
  state Enter will apply, never the current one.
- Typing a document name lists matching files below the actions as
  “Open: Chapter one”; Ctrl+K, a few letters and Enter open any file.
- The sheet draws the page behind it at about 40 % (the theme's paper over the
  page, the same dim as focus mode) and carries the shared card shadow. No
  animation.
- Running an action closes the palette before it runs; a toggle applies at
  once and shows its new state briefly above the bottom line.

## Key sheet

- Ctrl+/ opens a centred card listing every key, grouped as Writing, Files,
  Sync and export, and Screens, with key caps. Esc closes it. `?` stays an
  ordinary character in the editor. The page behind it is dimmed to about
  40 %, like the command palette.

## Hints and confirmations

- Every screen and both palettes' footers end with the same hint bar: at
  most five hints, each a rounded key cap and a short word, most useful first.
  The bar shows real bindings; every binding still works even when it is not
  shown.
- Destructive actions (delete a file or folder, restore a version, forget a
  network) use one confirmation component: the theme's paper as a centered
  card with a soft shadow, over the page dimmed with the theme's ink at 27 %.
  The card has a title, one short sentence, and two buttons. Cancel is focused
  by default; the other button names its action ("Delete", "Restore",
  "Forget"). Esc cancels, Enter activates the focused button, Left/Right/Tab
  move between them. No native alert windows or strips.
- Lists fade their top edge while scrolled, so no row is cut in half under the
  title; a selected row keeps a small margin at the edge.

## Screens

Every non-editor screen (Files, History, Sync, Wi-Fi, Export/Import, Settings,
First run) uses one page frame: a centered column 720 px wide, the title at the
same position, an optional one-line status under it, the content, and the key
hint bar at the same place at the bottom. History keeps its two panes inside
that frame.

- **Files**: folders and files, search by name, new folder, rename, move,
  delete (confirmation). Conflict copies marked. Document names are shown
  without their extension everywhere (the list, the delete title, Export's
  "Current file", History's subtitle); folders keep a trailing `/`. Rename
  happens in place: the selected row becomes an entry with the name selected
  and the `.md` extension hidden; Enter saves, Esc cancels.
  <!-- round 6 (Files, issue #27): search, recents, conflicts, move, new file -->
  - Typing letters filters the list at once, by name and case-insensitively
    (fuzzy) across every folder under the writing root; no field has to be
    focused first. The folder path follows the name in dim text, and a query
    that finds nothing says `No documents match “…”`. Backspace edits the
    query. Esc clears the query first; a second Esc leaves the screen.
  - Without a query, a "Recent" group above the folder tree lists the last
    five opened documents. Enter on one opens it; the Recent group is the
    first place the selection lands when Files opens.
  - A sync conflict copy (spec/02-sync-protocol.md) is shown by its base name
    with a "Conflict" tag. Enter opens the shared card with Keep mine / Keep
    theirs / Keep both; Esc leaves both files untouched. "Keep both" renames
    the copy to an ordinary unique name, so it stops being a conflict.
  - M (capital; plain letters type the search) moves the selected document.
    A short folder list with "New folder…" appears; Enter moves it, Esc
    cancels. Ctrl+Shift+N still creates a folder. Ctrl+N creates a document
    in the selected folder and opens the editor at once; the name comes from
    the first line, as on the editor screen.
  - Hint bar: `[Enter] Open · [Type] Search · [F2] Rename · [M] Move ·
    [Del] Delete`. Esc is implied. The move list swaps in its own three hints.
  <!-- /round 6 (Files, issue #27) -->
- **History**: list of versions by time with word count delta; preview; Restore
  (confirmation).
- **Quotes** (in the editor, not a screen): the same palette as the Nostos
  Writing Studio's `@` source palette, with the same trigger rules.
  - Typing `@` at the start of a word (after the start of a line, a space or
    no-break space, or one of `( [ " “ ‘ ' — –`) opens a small list at the
    caret. In the middle of a word (`me@example.com`) it does nothing.
    Ctrl+' opens it at the caret too (it types the `@`; closing with nothing
    typed takes it back).
  - The text after `@` is the live query, spaces allowed. It searches the
    quote, book, author and topics; an empty query lists the newest items. When
    the query is longer than 80 characters, has more than 8 words, starts with
    a space or has a double space, it is prose and the palette closes. It never
    opens inside a code span or a fenced code block.
  - Up/Down move; Enter inserts `> quote` + the citation link, replacing
    `@query`; Shift+Enter or Ctrl+Enter insert the citation link only. Esc
    closes and leaves the typed text as it is. The caret never leaves the
    editor, no mouse is needed, and one undo brings `@query` back.
  - States: "Searching…", "No quotes match “…”." and, when the paired server has
    no Nostos library, "Quotes need a Nostos account." (before the first sync:
    "Sync once to download your library.").
- **Export**: choose what (current file / a folder / everything), format
  (Markdown, Plain text, Word .docx, OpenDocument .odt, PDF, HTML, EPUB) and
  destination (USB drive). When a USB drive is plugged in, the screen lists it;
  without one it says "Insert a USB drive". "Everything" writes a dated folder
  (`Carrel export 2026-11-12/`) that keeps the folder structure. Citations
  become footnotes in .docx/.odt/PDF/EPUB. A finished export shows the path
  and "Safe to remove". **Import** from the same screen copies `.md`/`.txt`
  files from the USB drive into `/data/writing/Imported/`; the import flow and
  its result are titled "Import", not "Export". A finished import shows its
  result once: one line, "2 files imported into Imported.", and the hint bar;
  no status line, heading or second sentence.
- **Battery**: the bottom line shows the percentage and a charging mark. When
  F1 hides the bottom line, the battery still shows for 5 s at 10 % and 5 %.
  At 3 % the device saves, commits history and suspends. Values come from
  UPower over D-Bus.
<!-- UI round 7 (issue #28): grouped Settings and a two-Enter first run. -->
- **Settings**: four groups with small section labels in this order. Look:
  Theme (Automatic / Light / Sepia / Mist / Writer's Study / Dark / High
  contrast, each with a small swatch of its paper, ink and accent; Automatic
  shows one rectangle split into its day and night swatches), Day theme
  (indented under Theme and shown only while Automatic is chosen; default
  Light), Night theme (likewise; default Dark), Font (Serif / Sans / Mono),
  Size, then a short sample line in the current font and size so a change is
  seen at once.
  Writing: Daily goal, Goal progress, Focus mode, Typewriter mode, Spellcheck,
  Clock. Connections: Wi-Fi networks, Sync, Sync at shutdown. Device: Keyboard
  layout, Language, Time zone, Update, About.
  Up/Down move between value rows and step over the group labels; Left/Right
  change a value in place; Enter opens a screen only where one is needed
  (Wi-Fi networks, Sync, and a ready update). The selected row carries one
  short hint under it, aligned with the row text and in plain words; other
  rows show none. When an update is ready, one clear row sits at the top of
  Settings instead of the Update row at the bottom: "Update ready (0.2.0) —
  Enter to restart and update"; Enter restarts into the new version.
- **First run**: "Welcome to Carrel" with Language, Keyboard and Time zone
  already filled in (the image's keyboard layout, language and time zone when
  it has them, else English, US and Local time) and one action, "Start
  writing", which has the cursor. Changing any of the three opens its list and
  returns to the welcome screen. Then one optional step, "Connect sync?" (Not
  now / Nostos / Self-hosted server / Google Drive; Not now has the cursor),
  and the editor. Two Enters from power-on to the page.
<!-- end UI round 7 (issue #28) -->
<!-- UI round 4 (issue #29): Sync and Wi-Fi. -->
- **Sync**: the state is the hero: one large line at the top ("Up to date",
  "Syncing… 3 of 12 files", "Could not reach Nostos", "Not connected yet"),
  with the last sync time and the connected service(s) under it ("Connected to
  Nostos"). It is the largest text on the device (40 px, above the 30 px page
  title), because the state is what the writer came to see. When a service is
  paired, the only prominent action is "Sync now"; pairing another service and
  Unpair sit under a quiet "Connections" group. When nothing is paired, the
  screen offers the three services as choices with one line each saying what
  the writer gets (Nostos / Self-hosted server / Google Drive), not a menu of
  verbs. Unpair asks for confirmation. The shell remembers which services were
  paired in `.carrel/sync-ui.json`; when the daemon says nothing is paired,
  that memory is dropped and the three choices come back.
- **Sync errors**: every error says what to do next, in plain words, next to
  the state, with the one action that helps first. No network puts
  "No Wi-Fi. [Enter] Choose a network" first: Enter opens Wi-Fi, and once a
  network is connected Carrel returns to Sync and finishes the sync by itself.
  A server failure keeps the daemon's one sentence as the detail and offers
  "Sync now". An unpaired device shows the three service choices. From Wi-Fi,
  Esc is one step back to Sync when Sync opened it. Ctrl+Shift+S from the
  editor therefore always lands on the step that fixes the problem, never on a
  dead end.
- **Pairing**: the code is large, the QR sits beside it, and one sentence says
  what to do on the phone ("On your phone, scan the code or open
  app.nostos.page/pair and enter the code."). A live line says "Waiting for
  approval…", becomes "Paired." when the phone approves, and the screen
  returns to Sync by itself and syncs. Esc cancels pairing. The self-hosted
  flow asks for the server's address first; Google Drive shows its device code
  and stays one-way.
- **Wi-Fi** (Settings → Wi-Fi): scan list with a Wi-Fi fan for signal strength,
  a small padlock for a network that needs a password, and one short word,
  "Connected", for the network in use. The password field and every error that
  belongs to a network appear inline, in a row directly under that network's
  name, never at the bottom of the screen; a refused password keeps the field
  open with one line under it. Known networks are saved (NetworkManager).
  Hidden networks: "Other network…". The radio is on only while this screen is
  open, then blocked again. Captive portals (hotel login pages) are not
  supported, because they need a browser; the screen says "This network needs
  a login page. Use a phone hotspot." under the network.

## Visual

- Themes: the five Nostos themes (Light, Sepia, Mist, Writer's Study, Dark),
  for one ecosystem feel, plus High contrast (near-black on white). Every
  theme keeps body text at 7:1 or more and dim text at 4.5:1 or more against
  its paper.
- Automatic (the default) wears the day theme from 07:00 to 19:00 and the
  night theme otherwise, by local time; Carrel has no OS preference. New
  installs use Light by day and Dark by night. It switches live when the hour
  passes. The day slot offers Light, Sepia and High contrast; the night slot
  offers Mist, Writer's Study and Dark.
- Fonts (bundled, open licenses): a book serif (e.g. Source Serif 4), a sans
  (e.g. Inter), a mono (e.g. JetBrains Mono).
- Accent color: one color per theme, used ONLY for the text cursor, the
  hairline progress line and the selected row. Light and Sepia forest
  `#293E32`; Mist slate `#8494B0`; Writer's Study amber `#C9953E`; Dark mint
  `#8FBFAE`; High contrast blue `#0043CE`. Citation markers use the dim text
  color, not the accent.
- Palette: Light paper `#FFFFFF`, ink `#121316`; Sepia `#FBF4E5`, `#2B2118`;
  Mist `#1E2026`, `#C8CCD4`; Writer's Study `#1A1814`, `#E4D5BF`; Dark
  `#121318`, `#F0F1F4`; High contrast `#FFFFFF`, `#111111`. No pure black; only
  Light and High contrast use a pure white paper. Dim text is the ink mixed
  toward the paper until it clears 4.5:1 (about 55–65 %). A focused field
  draws a neutral ring of the ink, never the accent.
- Body text: 19 px default (range 16–24 via Ctrl+= / Ctrl+-), line height 1.6,
  column 60–75 characters measured with average character width.
- UI type scale, in pixels: page title 30, step heading 23, section label 15,
  row text the editor body size (never under 16), secondary text 15, hints 14,
  buttons 15. No UI text is smaller than 13 px at 1366×768.
- No animations except a ≤150 ms fade between screens. No caret animation, no
  keystroke sounds.
